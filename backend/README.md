# Backend - LoveLingua (Express + TypeScript)

Backend Node/TypeScript avec Express pour LoveLingua.

## 🚀 Démarrage

Installation des dépendances :

```bash
cd backend
npm install
```

Lancement en mode développement :

```bash
npm run dev
```

Build de production :

```bash
npm run build
npm start
```

## 🔌 Endpoint de test

- `GET /health` → renvoie un JSON `{ status: "ok", message: "API LoveLingua en ligne", ... }`
